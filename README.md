# 易耗品更换管家（ConsumableTracker）

家庭易耗品更换记录 App，原生安卓（Kotlin + Jetpack Compose）。

## 功能
- 清单页：按地址筛选，物品卡片显示下次到期、剩余天数、进度条、状态（正常/即将到期/已逾期）。
- 录入：右下角「+」填写物品名称、地址（可输新地址）、类别、首次更换日期、周期（月/年），实时算下次到期。
- 详情：点卡片进入，查看更换历史，可「记录本次更换」追加日期或删除某条历史。
- 提醒：到期自动加入系统日历日程；可设提前 7/15/30/60 天。
- 统计：总数/即将到期/已逾期 + 未来6个月到期分布。
- 备件库存（独立模块）：底部第 4 个 Tab「备件」，可增删改备件，字段为名称 / 存放位置（地址，可输新位置）/ 数量 / 备注；卡片上直接 +/− 调数量，按存放位置筛选。

## 运行方式
1. 用 Android Studio（Hedgehog 或更新）打开 `ConsumableTracker` 目录。
2. 等待 Gradle 同步（首次会下载依赖，需联网）。
3. 连上你的 vivo 手机（OriginOS 需开启「USB 调试」），或建一个安卓模拟器。
4. 点 Run ▶ 装到设备上。
5. 首次启动会请求日历读写权限（READ_CALENDAR / WRITE_CALENDAR），允许后到期提醒才会写入系统日历。

## 数据存储
- Room 数据库（items + replacements + spare_parts 三张表），items 表含 `calendarEventId` 字段记录对应日历事件；spare_parts 为独立备件表。
- 版本 v2→v3 升级时通过 `Migration(2,3)` 仅新建 `spare_parts` 表，原有更换记录数据不丢。

## 提醒机制（写入系统日历）
- 不使用闹钟/系统通知，改为把每条物品的「下次更换」写入**系统日历日程**：
  - 每次新增/删除/记录更换都会重新同步：事件从「下次更换 - 提前天数」当天 09:00 开始，
    到「下次更换日」09:00 结束，事件开始时由日历自动提醒（即提前 N 天）。
  - 事件带 `SYNC_ID = "consumable_<物品id>"`，重装/换机后可据此找回并覆盖旧事件。
- 需要日历读写权限；若本机没有任何可写日历账户（如未登录日历账号），则跳过写入、不弹提醒，App 其余功能不受影响。
